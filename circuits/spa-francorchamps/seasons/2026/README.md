# Spa-Francorchamps 2026

This directory contains the authoritative design, review, planning, project
control, evidence, validation, and release records for the Spa-Francorchamps
2026 Race Lab programme.

- `specs/` — approved product and calibration designs
- `reviews/` — independent review requirements, technical defence, and reconciliation ledgers
- `plans/` — implementation and closeout plans with stable task IDs
- `project/` — living status, append-only activity, decisions, lessons, and maintenance rules
- `manifests/` — source eligibility and data-cutoff records
- `reports/` — backtests, validation, and release decisions
- `artifacts/` — versioned publishable outputs

Begin resumed work with `project/README.md` and `project/STATUS.md`, then inspect
actual repository and PR state before relying on the recorded snapshot.

The calibrated Spa 2026 prediction remains unavailable until the specification's
release gates pass.
