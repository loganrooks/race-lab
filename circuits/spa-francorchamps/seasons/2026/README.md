# Spa-Francorchamps 2026

This directory contains the authoritative design, review, planning, evidence,
validation, and release records for the Spa-Francorchamps 2026 Race Lab
programme.

- `specs/` — approved product and calibration designs
- `reviews/` — independent review requirements and their technical defence
- `plans/` — implementation-planning documents
- `manifests/` — source eligibility and data-cutoff records
- `reports/` — backtests, validation, and release decisions
- `artifacts/` — versioned publishable outputs

The calibrated Spa 2026 prediction remains unavailable until the specification's
release gates pass.
